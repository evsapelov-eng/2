# Generative Organism, первый прототип (этапы A, B, C и D, частично)

Генеративное MIDI-устройство для Ableton Live 12 и Max for Live. Устройство не
перебирает случайные ноты, а выращивает музыкальный материал из ДНК: мотивов,
фраз, ритмических циклов и связи с общей гармонией. Мутации меняют гены, поэтому
новая версия остаётся родственной старой.

В этой поставке то, что ТЗ называет первым прототипом:

| Модуль ТЗ | Состояние |
|---|---|
| A. MIDI Core: синхронизация с транспортом Live, 4 голоса, каналы, Note Off, защита от зависших нот | сделано, проверено в симуляции |
| B. Generator Engine: MELODIC и RHYTHMIC, у каждого свой алгоритм | сделано |
| B. HYBRID и EXPERIMENTAL | **не сделано**, следующий этап; в интерфейсе их нет, чтобы не изображать несуществующее |
| C. Harmonic Foundation: Key, Mode, Length, Density, общая гармония для всех голосов | базовая часть: 11 западных ладов и пентатоник, аккорды строятся внутри лада |
| C. Historical Systems и Harmony Library | **не сделано**, этап C |
| D. ДНК, мутации, Manual, Auto и Hybrid, Freeze, Revert, Reset DNA, Stability | сделано |
| E. CAPTURE в MIDI-клип | **не сделано**, этап E; запись MIDI-файла (SMF) уже готова и проверена |
| F. Профили APC40 MK2 и Push 2 | все контролы уже параметры Live (MIDI Map работает); отдельных профилей нет |
| Сохранение состояния в Live Set | сделано (скрытый blob-параметр), в Live не проверено |

## Что лежит в папке

```
GenerativeOrganism/
├── device/                         что ставится в Live (собирается из src/)
│   ├── GenerativeOrganism.amxd     Max MIDI Effect
│   ├── GenerativeOrganism.maxpat   тот же патч в виде обычного файла Max (запасной путь)
│   └── organism.js                 весь движок для объекта [js]
├── src/
│   ├── engine/      util.js (seeded random), roles.js, melodic.js, rhythmic.js, generator.js
│   ├── harmony/     scale_library.js, harmonic_engine.js
│   ├── evolution/   evolution.js (ДНК, мутация, история), similarity.js (мера сходства для Stability)
│   ├── midi/        midi_engine.js (воспроизведение), smf.js (запись .mid)
│   └── max/         main.js (связь с патчем и Live API)
├── build/build.js   сборка organism.js, патча и .amxd
├── test/            20 автоматических тестов
├── tools/           render.js (демо в .mid), metrics.js (цифры Stability/Amount/Probability)
└── demos/           готовые .mid, полученные тем же движком
```

Исходники делятся по тем же модулям, что и в ТЗ (раздел 12.2). Код
написан на ES5, потому что классический объект `[js]` в Max 8 и Max 9 понимает
только ES5. Это проверяется тестом.

## Установка

1. Скопируйте папку `device/` целиком, например в
   `~/Music/Ableton/User Library/Presets/MIDI Effects/Max MIDI Effect/GenerativeOrganism/`.
   `GenerativeOrganism.amxd` и `organism.js` должны лежать рядом.
2. Перетащите `GenerativeOrganism.amxd` на MIDI-дорожку **перед** инструментом.
3. Запустите транспорт Live, и устройство начнёт играть.

**Если Live не откроет `.amxd`.** Контейнер `.amxd` собран скриптом без Max, и
его заголовок я не смог проверить на настоящем Live. Тогда так:

1. Положите на MIDI-дорожку пустой **Max MIDI Effect** и нажмите Edit.
2. В открывшемся Max удалите из патча стандартные `midiin` и `midiout`.
3. Откройте `device/GenerativeOrganism.maxpat`, выделите всё (Cmd+A), скопируйте и вставьте в патч устройства.
4. Сохраните устройство как `GenerativeOrganism.amxd` в ту же папку, где лежит `organism.js`.
5. Чтобы перенести устройство на другой компьютер, нажмите **Freeze Device**: `organism.js` встроится в `.amxd`.

## Управление

| Группа | Контрол | Что делает в алгоритме |
|---|---|---|
| GENERATOR | MELODIC, RHYTHMIC | выбирает генератор для всех четырёх голосов; при смене создаётся новая ДНК, старая доступна через REVERT |
| HARMONIC FOUNDATION | Key, Mode | меняют звучание той же ДНК: гены хранятся в ступенях лада, поэтому мотив и ритм сохраняются |
| | Bars (1, 2, 4, 8) | длина музыкального цикла; фраза перестраивается из тех же мотивов, гармония растягивается |
| | Density | до 75% прореживает ноты (по генам веса, одинаково при каждом повторе мотива), выше 75% добавляет проходящие ноты и ритмические доли |
| EVOLUTION | MANUAL, AUTO, HYBRID | MANUAL: только кнопка MUTATE. AUTO: только по часам. HYBRID: и то и другое |
| | Every (1, 2, 4, 8 тактов) | период автоэволюции; новое поколение считается за две шестнадцатых до границы такта и включается ровно на ней |
| | Mutation Amount | число генетических операций за одну мутацию и их величина |
| | Mutation Probability | доля элементов (нот мотива, долей, тонов), которые затрагивает операция, и вероятность мутации каждого голоса |
| | Stability | нижняя граница сходства с исходной идеей линии; мутация, вышедшая за неё, отбрасывается и повторяется слабее; кроме того, иногда возвращается ген исходной темы |
| | Complexity | длительности 1/16 и с точкой, широкие скачки, обращение и ракоход мотива, число ритмических слоёв, полиметрия, септаккорды |
| | Variation | вес скачков, пауз, синкоп, выпавших долей, неожиданных фразовых операций |
| VOICES | 1 Bass … 4 Texture | включение голоса |
| | Ch | MIDI-канал голоса (по умолчанию 1–4) |
| | Low, High | диапазон голоса; регистр генерации считается от его середины |
| | Dens | поправка плотности голоса (−50…+50%) |
| | Mut | глубина мутаций голоса; 0 запирает голос |
| | MUTATE | одна мутация; новое поколение включается на следующем такте |
| | FREEZE | останавливает AUTO и MUTATE; играющие ноты не обрываются |
| | REVERT | возврат к предыдущей ДНК (хранится 8 шагов) |
| | RESET DNA | новая исходная идея (старая остаётся в истории REVERT) |

Внизу устройства строка состояния: номер поколения, генератор, тональность и режим.

**Все 40 контролов — параметры Live.** Их можно назначить на APC40 MK2 через MIDI
Map Mode (Cmd+M) и автоматизировать. Push 2 показывает их в банках устройства.
Отдельная раскладка банков для Push 2 и APC40 запланирована на этап F.

**Четыре голоса выходят через один MIDI-выход и различаются каналом.** Чтобы
развести их по разным дорожкам Live с разными инструментами, на принимающей
дорожке нужен фильтр по каналу. Внутренняя маршрутизация Live фильтровать по
каналу не умеет. По ТЗ (п. 7.2) это проверяется отдельно и в этой поставке не
сделано.

## Как устроено

**Время.** `[metro 16n @quantize 16n]` тикает по сетке Live. На каждом тике
`[transport]` отдаёт bars, beats и units, а `organism.js` пересчитывает их в
абсолютный номер шестнадцатой с учётом размера такта (его даёт Live API). Время
берётся из транспорта Live, а не из собственного таймера, поэтому смена темпа,
перемотка и луп-скобка позиции не сбивают. Обработчик `pos` помечен
`immediate`, чтобы работать в потоке планировщика без задержки низкоприоритетной
очереди.

**MIDI-движок** (`midi_engine.js`):

- помнит каждую звучащую ноту вместе со временем окончания, поэтому Note Off
  приходит вовремя, даже если паттерн сменился, пока нота звучит;
- новый паттерн включает только на границе такта;
- повторный тик с тем же номером игнорирует, так что событие не дублируется;
- при скачке позиции сначала гасит все ноты;
- по Stop, при удалении устройства и при выключении голоса или смене его канала
  отправляет Note Off всем звучащим нотам.

**ДНК голоса в режиме MELODIC.** Мотив: ячейки с длительностью, интервалом в
ступенях, паузой и генами акцента, тяготения к аккорду, плотности и
расщепления. К нему прилагаются фразовый план (повтор, секвенция, вариант,
обращение, ракоход, фрагмент с дыханием, пауза), ген каденции с полукаденцией в
середине периода, тяготение сильных долей к аккордовым тонам, артикуляция. У
голоса Texture может быть ген канонической имитации мелодии. Фраза всегда
строится из мотива, поэтому изменение одного гена слышно как вариация всей
фразы.

**ДНК голоса в режиме RHYTHMIC.** От одного до трёх слоёв. Каждый слой — это
евклидов цикл собственной длины (16, 12, 7… шагов), и слои разной длины дают
полиритмию. К слою прилагаются гены синкоп, смещения акцентов (акцент через
3, 4 или 5 ударов идёт поперёк такта), рисунка «длинная/короткая», выпавших
долей и последовательности аккордовых тонов. У Harmony есть ещё ген аккордовых
ударов на 1–3 звука.

**Общая гармония.** Ген организма: последовательность корней по тактам, взятая
из шаблонов, характерных для лада. Например, i–IV в дорийском, I–♭VII в
миксолидийском, i–♭II во фригийском. Аккорды строятся терциями внутри лада. Её
читают все четыре голоса, и мутация может менять гармоническое движение, не
выходя из лада.

**Stability.** После каждой мутации движок считает, насколько новый материал
похож на исходную идею (совпадение атак и высот, от 0 до 1). Если сходство ниже
порога, который задаёт Stability, мутация отбрасывается и повторяется с меньшей
силой, до 8 попыток. Предыдущая ДНК не уничтожается, пока новая не прошла
проверку.

## Тесты

```
cd GenerativeOrganism
npm install        # только acorn, для проверки ES5
npm test           # сборка и 20 тестов
node tools/metrics.js
npm run render     # демо-файлы в demos/
```

Что проверяют 20 тестов (все проходят):

- все ноты в выбранном ладу и в диапазоне голоса: 11 ладов, 4 тональности, 4 длины цикла, оба генератора, с мутациями;
- детерминизм по seed;
- мелодические голоса монофоничны, и ритм мотива повторяется во фразе;
- больше 65% нот на сильных долях — аккордовые тоны;
- ритмы строятся из евклидовых слоёв, при высокой Complexity появляется полиметрия;
- Stability, Amount и Probability монотонно влияют на результат (цифры ниже);
- MUTATE всегда даёт слышимое изменение и сохраняет предыдущую ДНК; FREEZE, REVERT и RESET DNA работают; голос с Mut = 0 не меняется;
- смена тональности не меняет ритм;
- состояние сохраняется и восстанавливается без потерь, включая историю REVERT;
- MIDI: у каждого Note On есть Note Off при сменах паттерна посреди такта; паттерн меняется только на границе такта; повтор тика игнорируется; скачок позиции гасит ноты; каналы разделены;
- **обвязка Max:** `organism.js` выполняется в имитации окружения Max и Live
  (outlet, LiveAPI, транспорт с погрешностью ±1 тик). Проверено 40 тактов
  AUTO-эволюции, кнопки, выключение голоса, смена канала и генератора, Freeze,
  Stop без зависших нот, сохранение и загрузка в новый экземпляр;
- патч: код ES5, нет висячих соединений, каждый контрол доходит до движка, нет дублей имён параметров, интерфейс помещается в высоту устройства (169 px), заголовок `.amxd` корректен.

Сходство (1 означает «то же самое»), среднее по 16 линиям из 16 мутаций:

| с исходной идеей, Stability 1 | 0.92 | 0.92 |
| с предыдущим поколением, Amount 0.1 | 0.87 | 0.80 |

`demos/*.mid` — 32 такта автоэволюции, записанные тем же MIDI-движком: по
дорожке на голос, 110 BPM. Их можно перетащить в Live и послушать, как
развивается линия при высокой и низкой Stability.

## Что не проверено и известные ограничения

Live и Max в облачной среде разработки недоступны. **Устройство ни разу не
открывалось в настоящем Ableton Live.** Движок и обвязка проверены в Node, с
имитацией Max и транспорта. Ниже допущения о Max и Live, которые нужно
подтвердить на твоей машине:

1. **Заголовок `.amxd`.** Он собран по известной структуре (`ampf`, `mmmm`, `meta`, `ptch`). Если Live его не примет, есть запасной путь через `.maxpat` (см. «Установка»).
2. **Порядок выходов `[transport]`.** Предполагается, что первые три выхода — bars, beats и units, где units — тики при 480 на четверть.
3. **`live.text` в режиме кнопки** отдаёт 1 при нажатии. Отпускание (0) обвязка игнорирует.
4. **`pos.immediate = 1`.** Если в твоей версии Max это не сработает, ноты всё равно будут играть, но с небольшим джиттером низкоприоритетной очереди.
5. **Сохранение ДНК** в скрытом `pattr` с типом Blob вместе с Live Set: размер 15–60 КБ, частями по 2000 символов.
6. **Размеры, отличные от 4/4,** обработаны в коде, но не проверены. При 3/4 и мотиве в 16 шагов последний слот фразы обрезается.

Ограничения прототипа:

- разрешение сетки 1/16; длительности кратны 1/16;
- HYBRID, EXPERIMENTAL, исторические системы, Harmony Library, CAPTURE и аппаратные профили ещё не сделаны;
- FREEZE блокирует AUTO и MUTATE; REVERT и RESET DNA при этом работают, чтобы можно было откатиться (уточни, если нужно иначе);
- в режиме AUTO кнопка MUTATE не работает, как в ТЗ (5.2 и 5.3); для ручного вмешательства есть HYBRID.

## Проверка в Live (5 минут)

1. Устройство загружается без ошибок в Max Console (Max Window).
2. Play: звучат 4 голоса, сетка совпадает с метрономом. Повторите при 70, 120 и 170 BPM и при смене темпа во время игры.
3. Stop посреди длинной ноты: зависших нот нет.
4. MUTATE: изменение начинается со следующего такта. REVERT возвращает предыдущий вариант.
5. AUTO, Every 1: в строке состояния растёт GEN; звук меняется ровно на сильной доле.
6. FREEZE в AUTO: GEN перестаёт расти, звук не обрывается.
7. Луп-скобка на 1 такт и перемотка во время игры: нет зависших и сдвинутых нот.
8. Сохранить Live Set, закрыть, открыть: играет та же генерация, REVERT работает.

## Открытый вопрос

Какая версия Max установлена: Max 8, Max 9 или только встроенный в Live 12
Max for Live? Код рассчитан на классический `[js]` и должен работать в обоих.
От версии зависит, как собрать финальный `.amxd` и можно ли на этапе E
использовать `[v8]` для записи клипа.
