FLØCK v0.2.0 — ТЕСТОВАЯ СБОРКА для Ableton Live 12 (Max for Live Audio Effect)
=============================================================================

СТАТУС: собрано скриптом, в Ableton Live НЕ проверялось. Это не релиз.
Звуковой движок — перенос открытого кода Beads (Emilie Gillet, лицензия MIT,
см. LICENSE-BEADS.txt) в gen~. FLØCK не связан с Mutable Instruments.

УСТАНОВКА
1. Распакуйте папку FLOCK целиком (FLØCK.amxd и flock_ui.js должны лежать рядом).
2. Перетащите FLØCK.amxd на любую аудиодорожку (или после инструмента на MIDI-дорожке).
   Источник — любой звук: сэмпл, синт, голос, ресемплинг.
3. Один раз Freeze: Edit (гаечный ключ) → внизу снежинка Freeze Device → Cmd+S.
   Без Freeze переносить .amxd отдельно от папки нельзя (будет серый круг).

КАК ЭТО РАБОТАЕТ
FLØCK всё время записывает входящий звук в буфер (~4 с, «ленту»).
Гранулы — короткие кусочки этой записи — играются с разной позиции, высотой,
длиной и огибающей. До 32 гранул одновременно.

РУЧКИ
- TIME — откуда в записи берутся гранулы: слева свежий звук, справа ~4 с назад.
- DENSITY — частота гранул. Влево от 12 часов — ровно, вправо — случайно.
  Ровно 12 часов: при LATCH гранул нет, без LATCH — одна гранула на нажатие SEED.
- PITCH — транспонирование ±24 полутона, «защёлки» на 1, 3, 4, 7, 12, 24.
- SIZE — длина гранулы. Левее ~10 часов гранулы играют задом наперёд; вправо — до 4 с.
- SHAPE — огибающая: квадрат (щелчки) → затухание → колокол → медленная атака.
- RND под TIME/PITCH/SIZE/SHAPE — случайный разброс этого параметра у каждой
  гранулы. Вправо — равномерный, влево — «пиковый» (чаще малые отклонения).
  Любой разброс ещё и разносит гранулы по стерео.
- FEEDBACK — выход возвращается в запись (с ограничителем).
- DRY/WET — вход ↔ гранулы. REVERB — реверберация.
- IN / OUT — входное и выходное усиление (тянуть мышью).
- FREEZE — остановить запись: гранулы продолжают играть то, что уже в буфере.
- SEED — без LATCH: держите, чтобы шли гранулы (в 12 часов — одна на нажатие).
  Как на оригинале: короткое нажатие при включённом LATCH выключает LATCH,
  удержание SEED 4 секунды — включает. LATCH — гранулы идут постоянно.
- SIZE до упора вправо — в оригинале режим задержки; у нас он появится в v0.3.
Ручки: тянуть вверх/вниз, Shift — точно, двойной клик — по умолчанию.
Наведите мышь — внизу подсказка. Все ручки — параметры Live (автоматизация, Push).

ВКЛАДКА MOD — модуляция, ритм и нарезка (кнопки SOUND / MOD под логотипом)
Слева — шесть источников, справа — десять назначений. Тяните мышью провод от
гнезда источника к гнезду назначения (или наоборот). Клик по занятому гнезду
назначения — снять провод. В одно назначение входит один провод, как в гнездо
модуля. RANDOM — случайная коммутация (не больше MAX проводов), CLEAR — убрать все.
- LFO 1 / LFO 2 — RATE (Гц или, с SYNC, доля такта: 8 тактов … 1/32, триоли T,
  с точкой D), форма (синус / треугольник / пила / меандр), R — перезапуск при
  Play в Live, AMT — глубина.
- RANDOM — случайная модуляция: SMOOTH плавно, STEPS ступеньками.
- ENV — громкость входа (GAIN x0.25…x16).
- CLOCK — импульсы точно по темпу Live (1/4, 1/8, 1/16, триоли…).
  CLOCK → Seed: при LATCH ВЫКЛ одна гранула на импульс (DENSITY в 12 часов) —
  ровные гранулы восьмыми / шестнадцатыми. При LATCH ВКЛ — как клоковый режим
  оригинала: DENSITY влево делит импульсы (1…1/16), вправо прореживает (вероятность).
- SEQ — секвенсор на 16 шагов: клик по шагу — вкл/выкл, тянуть по шагу — значение;
  RATE — длина шага (1/16 и т.д.), LEN — длина рисунка 1…16 (3, 5, 7 — полиритм).
  SEQ → Seed — ритм гранул. SEQ → Time (ручку RND под TIME — вправо) — каждый шаг
  берёт свой кусок записи: НАРЕЗКА. С FREEZE — слайсер замороженного куска.
  SEQ → Pitch — мелодия гранул.
- Назначения Time / Pitch / Size / Shape работают как CV-входы оригинала: ручка RND
  под ними становится CV (вправо — глубина CV, влево — случайность, управляемая CV).
- Density, Freeze, Seed, Feedback, Reverb, Dry/Wet — как CV/гейт-входы оригинала;
  у Feedback / Reverb / Dry/Wet своя ручка глубины рядом с гнездом.
Синхронные источники стоят, пока Live остановлен, и идут точно по сетке при Play.

ЧТО БУДЕТ ДАЛЬШЕ (по плану)
v0.2 — 4 качества записи (Pristine / Cold digital / Sunny tape / Scorched cassette).
v0.3 — режим задержки (SIZE до упора), клок от темпа Live, слайсер.
v0.4 — режим WAVES (синтезатор без входа), MIDI.
v0.5 — сохранение замороженного буфера в Live-сете, вывод триггеров гранул.

ЕСЛИ ЧТО-ТО НЕ ТАК — пришлите скриншот и Max Console (Edit → Window → Max Console).
- серый круг вместо панели → .amxd открыт не из папки FLOCK и не заморожен
- на ленте надпись ENGINE NOT RUNNING или нет звука → пришлите текст из Max Console
  (в v0.1.0–0.1.1 код gen~ не компилировался в Max — исправлено в v0.1.2)
