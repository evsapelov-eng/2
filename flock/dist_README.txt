FLØCK v0.1.0 — ТЕСТОВАЯ СБОРКА для Ableton Live 12 (Max for Live Audio Effect)
=============================================================================

СТАТУС: собрано скриптом, в Ableton Live НЕ проверялось. Это не релиз.
Звуковой движок — перенос открытого кода Beads (Emilie Gillet, лицензия MIT,
см. LICENSE-BEADS.txt) в gen~. FLØCK не связан с Mutable Instruments.

УСТАНОВКА
1. Распакуйте папку FLOCK целиком (FLØCK.amxd и flock_ui.js должны лежать рядом).
2. Перетащите FLØCK.amxd на любую аудиодорожку (или после инструмента на MIDI-дорожке).
   Источник — любой звук: сэмпл, синт, голос, ресемплинг.
3. Один раз Freeze: Edit (гаечный ключ) → внизу снежинка Freeze Device → Cmd+S.
   Без Freeze переносить .amxd отдельно от папки нельзя (будет серый круг).

КАК ЭТО РАБОТАЕТ
FLØCK всё время записывает входящий звук в буфер (~4 с, «ленту»).
Гранулы — короткие кусочки этой записи — играются с разной позиции, высотой,
длиной и огибающей. До 32 гранул одновременно.

РУЧКИ
- TIME — откуда в записи берутся гранулы: слева свежий звук, справа ~4 с назад.
- DENSITY — частота гранул. Влево от 12 часов — ровно, вправо — случайно.
  Ровно 12 часов: при LATCH гранул нет, без LATCH — одна гранула на нажатие SEED.
- PITCH — транспонирование ±24 полутона, «защёлки» на 1, 3, 4, 7, 12, 24.
- SIZE — длина гранулы. Левее ~10 часов гранулы играют задом наперёд; вправо — до 4 с.
- SHAPE — огибающая: квадрат (щелчки) → затухание → колокол → медленная атака.
- RND под TIME/PITCH/SIZE/SHAPE — случайный разброс этого параметра у каждой
  гранулы. Вправо — равномерный, влево — «пиковый» (чаще малые отклонения).
  Любой разброс ещё и разносит гранулы по стерео.
- FEEDBACK — выход возвращается в запись (с ограничителем).
- DRY/WET — вход ↔ гранулы. REVERB — реверберация.
- IN / OUT — входное и выходное усиление (тянуть мышью).
- FREEZE — остановить запись: гранулы продолжают играть то, что уже в буфере.
- SEED — без LATCH: держите, чтобы шли гранулы. LATCH — гранулы идут постоянно.
Ручки: тянуть вверх/вниз, Shift — точно, двойной клик — по умолчанию.
Наведите мышь — внизу подсказка. Все ручки — параметры Live (автоматизация, Push).

ЧТО БУДЕТ ДАЛЬШЕ (по плану)
v0.2 — 4 качества записи (Pristine / Cold digital / Sunny tape / Scorched cassette).
v0.3 — режим задержки (SIZE до упора), клок от темпа Live, слайсер.
v0.4 — режим WAVES (синтезатор без входа), MIDI.
v0.5 — вкладка MOD: LFO, Random, огибающая, клок и матрица проводов.

ЕСЛИ ЧТО-ТО НЕ ТАК — пришлите скриншот и Max Console (Edit → Window → Max Console).
- серый круг вместо панели → .amxd открыт не из папки FLOCK и не заморожен
- нет звука / ошибка gen~ в Console → пришлите текст ошибки (gen~ в Max ещё не проверялся)
