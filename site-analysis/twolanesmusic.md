# Разбор сайта twolanesmusic.com

Дата разбора: 6 ноября 2026. Сайт открывался в браузере (Playwright) на компьютере (1440×900) и на телефоне (iPhone 13).

## Платформа

- Конструктор **Squarespace 7.1**. Своего кода почти нет: только небольшой `custom.css` (иконка TikTok через свой шрифт-иконку и плавная прокрутка `scroll-behavior: smooth`).
- Магазин (STORE) — внешняя ссылка на **Shopify** (`twolanesshop.myshopify.com`).
- Концерты (LIVE) — стандартный блок Squarespace «Tour dates», данные берёт из **Bandsintown** по имени артиста.
- Ноты — PDF-файлы, загруженные в Squarespace (`/s/*.pdf`).

## Страницы

| Страница | Что на ней |
|---|---|
| HOME | Экран 100% высоты: фоновое видео YouTube на весь экран, пока грузится — фото. Ни текста, ни кнопок. |
| LIVE | Заголовок + список концертов из Bandsintown (сейчас «нет предстоящих дат»). |
| SHEET MUSIC | Заголовок + два раскрывающихся блока (аккордеон) в две колонки: «книга нот» (ссылка в магазин) и «скачать бесплатно» (список PDF курсивом). |
| STORE | Ссылка на внешний магазин Shopify. |
| CONTACT | Заголовок + три колонки: менеджмент, букинг Северная Америка, букинг Европа (e-mail-адреса). |

Подвала нет. Корзина (`/cart`) есть, но в шапке не показана.

## Шапка (header)

- Закреплена сверху (`position: fixed`), **прозрачная**, текст белый, лежит поверх фото/видео.
- Три зоны в одну строку:
  - слева меню: HOME · LIVE · SHEET MUSIC · STORE · CONTACT — 15px, обычное начертание, прописные буквы;
  - по центру название: **TWO LANES** — 30px, жирный;
  - справа иконки соцсетей: Instagram, YouTube, Twitter, Spotify, Apple Music, TikTok.
- Поля по бокам примерно 110px на ширине 1440px.
- Переходы: `background 0.3s ease-in-out`, `padding 0.14s`, `transform 0.14s`.

## Мобильная версия

- Шапка: название слева (23px, жирный), справа бургер из **двух тонких линий**.
- Нажатие открывает **меню на весь экран**: чёрный фон, пункты крупно (около 40px) по центру, иконки соцсетей внизу, бургер превращается в тонкий крестик.
- Анимация меню: фон проявляется за 400 мс, список выезжает снизу на 20px за 600 мс, кривая `cubic-bezier(.4, 0, .2, 1)`.

## Графика

- **Главная:** фото дуэта силуэтами на сцене, холодная серо-синяя гамма, тёмный низ, заметное **плёночное зерно**. Поверх него на компьютере играет фоновое видео YouTube (без звука, по кругу).
- **Внутренние страницы:** чёрный фон с почти невидимой тёмной текстурой с зерном (`grain bw.jpg`), сквозь которую едва угадываются силуэты.
- Минимализм: никаких рамок, кнопок, теней и разделителей. Только белый текст на чёрном и фотография.

## Шрифты

- Везде один шрифт: **Aktiv Grotesk** (Adobe Fonts, нужна подписка Adobe).
- Начертания: 400 (текст, меню), 500 (кнопки), 700 (заголовки, название).
- Размеры: H1 — 4rem (60px), H2 — 2.8rem, H3 — 2.2rem, H4 — 1.2rem; основной текст 15px, межстрочный интервал 1.8.
- Заголовки страниц набраны **прописными**: SHEET MUSIC, CONTACT, LIVE.
- **Бесплатная замена**, очень близкая по виду: **Inter** (Google Fonts). Ещё варианты: Hanken Grotesk, Instrument Sans.

## Анимации и поведение

- Анимации появления блоков при прокрутке **выключены** (`animation-type: none`).
- Из движения есть только:
  - фоновое видео на главной;
  - открытие и закрытие мобильного меню (см. выше);
  - аккордеон на странице нот: стрелка-шеврон поворачивается вверх, блок раскрывается;
  - плавная прокрутка страницы.
- Вся «атмосфера» держится на фото, зерне и крупной жирной типографике, а не на эффектах.

## Как повторить механику для своего проекта

Сайт простой, конструктор не нужен. Хватит обычных HTML, CSS и немного JavaScript, а бесплатный хостинг даёт GitHub Pages.

1. Общая шапка: меню слева, название по центру, соцсети справа; на телефоне — бургер и полноэкранное меню с той же анимацией.
2. Главная: видео или фото на весь экран с зерном.
3. Концерты: виджет Bandsintown (бесплатный) или свой список дат.
4. Ноты или релизы: аккордеон в две колонки со ссылками.
5. Контакты: три колонки с e-mail.
6. Магазин: ссылка на внешний магазин, если он есть.

Тексты, фото, название и логотип — ваши. Чужие фото и тексты не копируются.
