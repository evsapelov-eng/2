# FLOW — план тестирования

Три уровня, и они не подменяют друг друга:

1. **AUTO** — `npm test` в Node: логика скриптов на симуляторе (`tests/sim/live-sim.js`) и статическая проверка патча/`.amxd`. Доказывает только внутреннюю корректность кода. **Не доказывает** поведение Live.
2. **LIVE** — ручные прогоны в Ableton Live 12 на Mac по протоколам (`M0_SPIKE_PROTOCOL.md`, далее — протоколы M1–M5).
3. **HW** — испытания с Digitone II (H01–H09).

Статусы: `PASS` / `FAIL` / `NOT RUN`. Статус «готово» без LIVE-прогона не ставится.
