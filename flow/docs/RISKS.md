# Технические риски и известные ограничения

| # | Риск | Влияние | Что делаем / чем проверяем |
|---|---|---|---|
| R1 | Бинарный формат `.amxd` воссоздан по открытым описаниям, а не по спецификации | Вариант A установки может не открыться | Вариант B (ручная сборка в Max), M0-INST |
| R2 | JS работает в low-priority потоке; задержка Task переменная (DOC) | Опоздание команды у границы → лишний оборот / пропущенный HOLD | Точные границы отдаются Live (wrap, квантованный `CuePoint.jump`); E1/E5/E6 дают безопасный запас |
| R3 | Неизвестно, квантуется ли `current_song_time` при игре | NEXT на произвольную цель может быть неточным | E7; без локатора на цели NEXT вперёд → EXPERIMENTAL |
| R4 | Поведение Live при `loop=1`, если playhead уже прошёл конец петли | Поздний HOLD может неожиданно прыгнуть назад | E6 (отрицательные запасы); по умолчанию поздний HOLD отклоняется |
| R5 | Прыжки транспорта: обрыв хвостов реверба/дилея, повторный старт аудиоклипов с середины, скачки автоматизации | Слышимые артефакты | Слуховая оценка в E7–E9; рекомендации по подготовке стемов попадут в USER_GUIDE (M5) |
| R6 | Digitone ставит Program Change в очередь до конца паттерна | Паттерн сменится позже секции | M4: pre-send lead, тест 16/32/64 steps; `REQUESTED`, а не `CURRENT` |
| R7 | Session-клипы перекрывают Arrangement | FLOW «управляет» не тем, что звучит | `back_to_arranger` observe (DOC) → предупреждение; E12 |
| R8 | Пользователь двигает Loop brace во время HOLD | Конфликт владения | MANUAL OVERRIDE; E11 проверяет, приходят ли уведомления |
| R9 | Смена темпа / размера такта внутри Set (автоматизация темпа) | Ошибка перевода в такты и в мс | Темп наблюдается постоянно; смены размера в MVP явно запрещаются (E2 проверяет базовую арифметику) |
| R10 | Несколько экземпляров FLOW | Два мастера транспорта | M3, T14 |
| R12 | `stop` на остановленном транспорте сбрасывает позицию в начало (producer-pal) | Случайный сброс места в сете | STOP проверяет `is_playing` |
| R13 | Прыжок вперёд без локатора — только по JS-таймеру | Отклонение на десятки мс | По умолчанию запрещён (SAFE); EXPERIMENTAL явно помечен |
| R14 | Формат blob-pattr и live.text воспроизведён по чужим устройствам, не по спецификации | Хранение или кнопки могут не заработать | Сверено с SIGNe, looper-dash, Ableton maxdevtools; проверяется установкой + T01 |
| R11 | FLOW не прошёл ни одного запуска в Live | Любая ошибка интеграции видна только на Mac | SELF-TEST + отчёт |
