## 2026-11-20 — Milestone 0, среда разработки

Среда: Linux-контейнер (x86_64), Node v22.23.5, Python 3. **Ableton Live и Max недоступны**, Mac к сессии не подключён.

### AUTO (`npm test`) — 30 / 30 PASS

Что подтверждено (только логика, на симуляторе):
- скрипт не трогает LiveAPI в global code; инициализация только после `live.thisdevice`;
- ни одна команда Live не отправляется из колбэка observer'а (симулятор бросает ошибку, как Live, и нарушений нет);
- при загрузке транспорт и Loop не меняются;
- эксперименты корректно **различают** альтернативы неизвестного поведения Live: clean/extra cycle, held/missed, jumped back/no jump, immediate/quantized seek;
- перевод в такты для 4/4 и 3/4 согласован с форматом `bars.beats.sixteenths.ticks`;
- патч: все соединения валидны, каждая кнопка имеет обработчик в JS, есть MIDI pass-through, элементы помещаются в высоту устройства (169 px);
- `.amxd`: чанки `ampf/mmmm/meta/ptch` содержат тот же JSON, что и `.maxpat`.

Ограничение: параметры симулятора (задержка команд, частота observer'а, квантуется ли seek) — допущения, а не факты Live.
