# Конфиденциальность и данные

## Что хранится

| Данные | Где | Срок |
|---|---|---|
| Тексты постов канала | Зашифрованное состояние | Бессрочно (публичный контент канала) |
| Комментарии, имя, username и Telegram ID комментатора | Зашифрованное состояние | `data_retention_days` (по умолчанию 90 дней, меняется в настройках) |
| Результаты анализа, рекомендации, идеи | Зашифрованное состояние | Вместе с комментарием; идеи — бессрочно, без текста комментария |
| Очередь уведомлений (содержит тексты) | Зашифрованное состояние | 3 дня после отправки |
| Сообщения из посторонних групп и чатов | Не сохраняются | — |

Состояние шифруется AES-256-GCM (библиотека `cryptography`), ключ есть только в
GitHub Secrets. В ветке `bot-state` всегда один коммит, без истории версий; старые
версии становятся недостижимыми и удаляются сборщиком мусора GitHub. Для полной и
немедленной очистки удалите ветку `bot-state` целиком (бот начнёт с нуля) и при
необходимости обратитесь в поддержку GitHub с просьбой очистить кэш.

В логах GitHub Actions пишутся только счётчики: тексты комментариев, имена, токены
и ключи не выводятся. Логи httpx (в URL Bot API есть токен) отключены.

## Что уходит в Gemini

- текст поста (до 1500 символов);
- текст комментария, родительского сообщения и до трёх предыдущих сообщений ветки;
- метка «автор» или «подписчик» вместо имён — **имена, username и ID не передаются**;
- до пяти последних ответов автора как образец стиля.

**Важно.** На бесплатном тарифе Gemini API Google по условиям для бесплатных сервисов
может использовать переданные данные для улучшения своих продуктов, в том числе с
привлечением людей-рецензентов. Проверьте актуальную редакцию:
https://ai.google.dev/gemini-api/terms. Если это неприемлемо — не задавайте
`GEMINI_API_KEY`: бот будет работать в режиме анализа по правилам. До вашего
решения рекомендуется тестировать бота на тестовом канале с вымышленными
комментариями.

## Удаление данных подписчика

Команда в личном чате с ботом:

```
/forget 123456789
/forget @username
```

Удаляет все комментарии подписчика, результаты анализа и рекомендации. Из резервной
копии данные исчезают при следующем сохранении состояния (в конце того же запуска).

## Текст для подписчиков

Предлагаемый текст для закреплённого сообщения или описания группы:

> Комментарии в обсуждениях PLUIT Club читает помощник автора — бот, который
> помогает не пропустить ваши вопросы и истории. Он ничего не пишет от имени автора
> и никому не отвечает сам. Для анализа тексты комментариев (без имён) могут
> передаваться сервису Google Gemini. Комментарии хранятся в зашифрованном виде не
> дольше 90 дней. Чтобы удалить свои данные, напишите автору.
