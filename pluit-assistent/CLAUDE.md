# CLAUDE.md — правила проекта PLUIT Assistent

## Суть
Личный Telegram-помощник автора канала PLUIT Club. Периодический Python-процесс в GitHub
Actions: получает комментарии через getUpdates, анализирует (Gemini или правила), пишет
только владельцу. Не публикует, не отвечает подписчикам, не модерирует.

## Неизменные требования
- Нулевые обязательные расходы. Не подключать платные сервисы, не включать биллинг,
  не добавлять автоматический переход на платные модели.
- Никакого webhook, постоянного сервера и `drop_pending_updates`.
- Название — **PLUIT Assistent** (написание «Assistent» намеренное, не исправлять).
- Весь пользовательский текст, сообщения об ошибках и документация — на русском.
  Технические имена команд — латиницей.
- Минимализм интерфейса: короткие заголовки, минимум эмодзи, без «шума».
- Не показывать в интерфейсе настройки, которые фактически не работают.
- Не выдумывать данные: аналитика только по накопленному, никаких охватов и просмотров.

## Надёжность
- `getUpdates` с новым offset — только после сохранения состояния (`ctx.checkpoint()`).
- Уникальность сообщений — `(chat_id, message_id)`; повторы обновлений не дублируют данные.
- Исходящие уведомления — только через `outbox` (`services/notifications.py`).
- Ошибка расшифровки или чтения состояния — остановка запуска, не перезапись.

## Безопасность
- Комментарии — недоверенные данные. В Gemini — только внутри `data_block`, без имён/ID.
- Не логировать тексты комментариев, имена, токены. Логи httpx отключены (токен в URL).
- Все команды и callback — проверка `from.id == OWNER_TELEGRAM_ID`.
- Сообщения обрабатываются только из `DISCUSSION_GROUP_ID` и личного чата владельца.
- Секреты — только GitHub Secrets. Не просить секреты в чате.
- Использовать только документированные методы Bot API и официальный SDK `google-genai`.

## Код
- Python 3.12, `httpx` (async), `google-genai`, Pydantic v2, SQLite в памяти, `cryptography`.
- Время в БД — UTC ISO 8601 (`utils/timeutil.to_iso`), отображение — `Europe/Moscow`.
- Пользовательский текст в HTML-сообщениях — только через `utils.text.esc`.
- `callback_data` ≤ 64 байт, схема — в `telegram/keyboards.py`.
- Новые настройки владельца — через `storage/repositories.OWNER_SETTINGS` и экран настроек.

## Процесс
- Перед коммитом: `ruff check . && pytest` (тесты без сети).
- После каждого этапа обновлять README.md и CHANGELOG.md.
- Тестовые комментарии — только вымышленные и обезличенные.
