# NØIZ — проверка на Mac (Ableton Live 12 Suite)

Цель — пройти «ворота» P1 → P2 → P3 из ТЗ на настоящем Live. Каждый шаг заканчивается записью в `docs/ACCEPTANCE_TESTS.md`: PASS / FAIL / NOT TESTED, дата, версии Live и Max, доказательство (скриншот Max Console, запись звука).

## Быстрый путь: готовая тестовая сборка

Скачайте `noiz/dist/NOIZ_v0.2.0_test_build.zip` (или папку `noiz/dist/NOIZ/`), распакуйте, все файлы держите в одной папке, перетащите `NØIZ P1 hello.amxd`, затем `NØIZ.amxd` на новые MIDI-дорожки. Подробно — `README_FIRST.txt` в папке. Если Live не принимает файл или устройство пустое — используйте штатный путь ниже (шаги 1–2): те же патчи, но сохранённые самим Live.

Подготовка для штатного пути: склонируйте репозиторий (ветка `claude/awesome-newton-q5h9ut`) и держите под рукой папку `noiz/max/`.

---

## Шаг 0. Окружение (P0)

1. Live → *About Live*: запишите версию (12.x) и редакцию (Suite).
2. Откройте любой Max-девайс → *Edit* → в Max: *About Max* — версия Max (встроенный в Live или отдельный).
3. Apple Silicon / Intel, версия macOS.
4. Впишите в `docs/ENVIRONMENT.md`.

## Шаг 1. P1 — минимальный Max Instrument (без JS)

1. В браузере Live: *Max for Live → Max Instrument* — перетащите на **новую MIDI-дорожку**. Должен появиться инструмент (а не «Drop Instrument Here»).
2. Нажмите кнопку *Edit* на устройстве → откроется редактор Max.
3. В редакторе: *File → Open* `noiz/max/p1_hello_hiss.maxpat`. В открывшемся патче: *Edit → Select All*, *Copy*.
4. Вернитесь в окно девайса, удалите стандартные объекты шаблона, *кроме* `plugout~` (если он есть — тогда после вставки удалите лишний второй `plugout~`), вставьте (*Paste*).
5. *File → Save As…* → `NOIZ_P1.amxd` в отдельную папку. Закройте редактор.
6. Кликните TRIG на устройстве → **короткий шипящий щелчок**.
7. Удалите устройство, перетащите `NOIZ_P1.amxd` на чистую MIDI-дорожку → снова TRIG → звук.
8. *Max Window* (Console): нет ошибок.

**Done (P1):** звук есть; Console чистая; файл создан штатным Save. → LIVE LOAD VALID + AUDIO VALID (для hello-world).

## Шаг 2. Полное устройство NØIZ (P2–P4, диагностический UI)

1. Новый *Max Instrument* на новой MIDI-дорожке → *Edit*.
2. В редакторе девайса: *File → Save As…* → `NOIZ.amxd` **в папку `noiz/max/`** (рядом с `noiz_engine.js`, `noiz_ui.js`, `noiz_voice_*.maxpat` — так Max их найдёт).
3. *File → Open* `noiz/max/noiz_main.maxpat` → *Select All* → *Copy* → в окно `NOIZ.amxd` → удалить стандартные объекты шаблона (включая его `plugout~`: в нашем патче он свой) → *Paste*.
4. Patcher Inspector устройства (*View → Inspector Window*, клик по пустому месту): **Open in Presentation = on**, **Device Width = 760**.
5. Проверьте объект `pattr noiz_state` в Inspector: *Parameter Mode Enable* = on, *Type* = **Blob**, *Visibility* = **Stored Only**. Если нет — выставьте вручную (см. `MAX_API_TO_VERIFY.md` #8).
6. *Save*. Закройте редактор.
7. Max Console: нет красных объектов, нет `js:` ошибок. Если есть — скопируйте текст ошибки целиком, это первое, что нужно исправить.

### Проверки (запишите результат в ACCEPTANCE_TESTS.md)

| Тест | Действие | Ожидание |
|---|---|---|
| A01 | устройство на MIDI-дорожке | инструмент, звук в канал дорожки |
| A03 | Play в Live, без MIDI-нот | играет встроенный паттерн, в UI `SYNC LIVE`, BPM как в Live |
| A04 | M на трёх дорожках → слушать по одной | 4 разных тембра |
| A05 | у каждой дорожки потянуть TONE/DECAY/TEXTURE/DRIVE 0→100% | слышимое изменение у всех 16 |
| A06 | GENERATE 10 раз | разные пригодные ритмы, без «все 16» и без тишины |
| A07 | AMOUNT = 0 → MUTATE | ничего не меняется |
| A08 | AMOUNT ≈ 15% → MUTATE | ритм узнаваем |
| A09 | KEEP, MUTATE, MUTATE, UNDO, UNDO | варианты различаются, возврат корректен |
| A10 | R и S на дорожке → GENERATE/MUTATE во всех scope | залоченная дорожка не меняется |
| A11 | option+клик по шагу 7 → тянуть DECAY вниз | шаг 7 короче, остальные — нет |
| A14 | option+клик по шагу → PROB тянуть до 0% / 100% | при 0% шаг молчит, при 100% звучит всегда |
| A15 | option+клик → RAT x4 при 120 BPM | 4 равномерных удара внутри шага |
| A17 | DIV: 3:4, 5:4 | количество ударов за долю совпадает (записать аудио, сравнить с сеткой) |
| A16 | DUST LEN 13 | DUST не «перезапускается» на каждом такте |
| A18 | менять темп 80→160 во время игры | нет двойных ударов, фраза не съезжает |
| A19 | loop 1 такт, seek, stop/start | нет двойных ударов на стыке петли |
| A20 | сохранить Live Set, закрыть, открыть | паттерн, P-Locks, locks, seed восстановлены |
| A25 | все дорожки, ratchet высокий, DRIVE 100% | нет клиппинга, Max не зависает |
| A26 | ширина устройства в цепочке | весь UI виден, нет «серого круга» |

### Что прислать мне после проверки

1. Скриншот устройства в Live и текст Max Console (даже если пустой — скажите «пусто»).
2. Таблицу PASS/FAIL выше.
3. Если звук есть — 10–20 секунд записи (Resample-дорожка) после GENERATE.

После этого: исправления по найденному → P5 (Compact ≤ 640 px) → P6 (полный редактор) → P7 (аудиореактивные ноды и клубок нитей) → P8 (Freeze и чистое переоткрытие).

## Шаг 3 (позже, P8). Freeze

Только когда всё выше PASS: в редакторе девайса кнопка **Freeze Device** → Save → перенести `NOIZ.amxd` в **другую** папку без исходников → открыть в новом Live Set → звук и UI на месте (A02).
