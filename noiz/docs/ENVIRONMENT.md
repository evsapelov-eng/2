## Честные ограничения разработки

- В этой среде нельзя открыть Max/Live, поэтому достижимый максимум — **STATIC VALID**: модульные тесты ядра, проверка JSON/связей патчей, офлайн-рендер эталонной модели DSP.
- `.amxd` не генерируется (ТЗ §13, §16.1): устройство собирается штатным Save в Live по `HOST_TEST_GUIDE.md`.
- API Max, написанные по памяти, перечислены в `MAX_API_TO_VERIFY.md`.
- Старые сборки v0.1–v0.6 из прошлых попыток в этот репозиторий не переносились и не использовались.

## Выбранный минимальный стек

MSP (`noise~`, `pink~`, `svf~`, `cycle~`, `line~`, `tanh~`, `poly~`) · `[transport]` + `[qmetro]` + lookahead + `[pipe]` · `[js]` (ES5, один самодостаточный файл) · `[jsui]` + mgraphics · `[pattr]` Blob-параметр. Без gen~, без jit, без внешних npm-модулей.
