# CONTROL AUDIT (ТЗ §17)

Каждый видимый контрол: (1) задача, (2) куда идёт, (3) нельзя ли существующим, (4) что слышно/видно, (5) как проверить в Live.

| Контрол | (1) Задача | (2) Связь | (3) Дубль? | (4) Слышно / видно | (5) Проверка |
|---|---|---|---|---|---|
| Шаг (клик) | вкл/выкл удар | `toggle` → `steps[i].on` → scheduler | нет | удар появляется/пропадает | A03, A06 |
| Option+клик шаг / «x» | режим STEP (P-Lock шага) / выход | `selstep` | нет | рамка 1.5 px, «STEP nn» | A11 |
| Имя дорожки | выбрать голос | `select` | нет | маркер у имени | — |
| M | mute | `mute` → scheduler пропускает дорожку | нет | дорожка молчит, хвосты доигрывают | US-08 |
| L | защита голоса от GENERATE/MUTATE (ритм + звук + P-Locks) | `hold` → locks.rhythm + locks.sound | заменил R и S (v0.2) | залитый флажок | A10 |
| 1 / 2 | страница 17–32 | `page` | показывается только если есть дорожка длиннее 16 | номера шагов | — |
| LEN | длина цикла | `tracklength` | нет | шаги за длиной — прочерк | A16 |
| DIV | полиритм n:m | `division` → stepBeats = 0.25·m/n | нет | темп ударов дорожки | A17 |
| VEL / PROB / RAT (STEP) | velocity / вероятность / дробь шага | `stepset` | нет | громкость / пропуски / дробь | A14, A15 |
| SEQ / LANE / SYNTH | экраны | `view` | заменил RHY/SND/PLK/ALL (v0.2) | — | — |
| GENERATE | всё: ритм, звук, синтез, панорама, значения по шагам (кроме L) | `generate` → scope ALL | нет | новый паттерн и звук (след. такт при игре) | A06 |
| MUTATE | вариация всего от Keep | `mutate` → scope ALL | нет | узнаваемая вариация | A08, A09 |
| LANE: выбор параметра | какой параметр рисовать по шагам | локальное состояние UI | нет | заголовок «… PER STEP» | новый |
| LANE: столбики | значение параметра на шаге | `lane` → P-Lock; `clearlock` | нет | залитый = своё значение, контур = голос | A11 |
| SYNTH: картинка | показать, что делает каждый параметр | модель голоса `js/shared/noiz_dsp_model.js` | не контрол | волна, 10 мс, спектр, полоска панорамы | A23* |
| KEEP / UNDO | опорная точка / откат | `keep` / `undo` | нет | — | A09 |
| AMOUNT | сила MUTATE | `amount` | один на устройство | 0% — без изменений | A07, A08 |
| CLR | стереть P-Locks шага | `clearsteplocks` | виден только если у шага есть P-Locks | точка P-Lock исчезает | A11 |
| TONE | яркость | частота фильтра / основной тон партиалов | нет | темнее → ярче | A05 |
| DECAY | длина | время огибающей | нет | щелчок → хвост | A05 |
| TEXTURE | окраска шума | white/pink/крэкл; METAL: шум vs партиалы | нет | гладко → пыльно | A05 |
| DRIVE | насыщение | tanh(g·x)·g^−0.6 | нет | плотнее без скачка громкости | A05 |
| PAN | место в стерео (BASE или P-Lock шага) | панорама равной мощности на удар | нет | L ↔ R | новый |

| SPREAD | разброс панорамы по ударам | детерминированный hash(seed, шаг, цикл); ratchet — проход по базе | нет | удары «летают» по стерео | новый |
| LEVEL | громкость голоса | dB → amp в триггере | нет | — | US-08 |

Удалены в v0.2 как дублирующие или не дающие слышимого результата сами по себе: RHY/SND/PLK/ALL, LK DENS, LK AMT, DENS, R, S, BASE (выход из STEP — «x» или повторный option+клик). Плотность и параметры случайных P-Locks остаются внутренними значениями движка (0.35 / 0.25).

Все 9 звуковых параметров можно задать на каждом шаге (P-Lock) — с SEQ (STEP), SYNTH (STEP) и LANE. LEVEL — только на голос.

Нет ни одного контрола без связи с DSP или event engine. Ноды пока не аудиореактивны (P7) — их форма отражает только значение параметра.
