# CONTROL AUDIT (ТЗ §17)

Каждый видимый контрол: (1) задача, (2) куда идёт, (3) нельзя ли существующим, (4) что слышно/видно, (5) как проверить в Live.

| Контрол | (1) Задача | (2) Связь | (3) Дубль? | (4) Слышно / видно | (5) Проверка |
|---|---|---|---|---|---|
| Шаг (клик) | вкл/выкл удар | `toggle` → `steps[i].on` → scheduler | нет | удар появляется/пропадает | A03, A06 |
| Option+клик шаг | выбрать шаг для P-Lock | `selstep` → режим STEP | нет | рамка 1.5 px, «STEP nn» | A11 |
| Имя дорожки | выбрать голос | `select` | нет | маркер слева от имени | — |
| M | mute | `mute` → scheduler пропускает дорожку | нет | дорожка молчит, хвосты доигрывают | US-08 |
| R / S | защита ритма / звука (+P-Locks) от генерации | `lockr` / `locks` → engine | нет (это не mute) | залитый флажок | A10 |
| 1 / 2 | страница шагов 17–32 | `page` | нет | номера шагов | — |
| LEN | длина цикла дорожки | `tracklength` → `length` | нет | шаги за длиной — прочерк | A16 |
| DIV | полиритм n:m | `division` → stepBeats = 0.25·m/n | нет | темп ударов дорожки | A17 |
| DENS | целевая плотность Generate | `density` → generator | нет | число ударов после Generate | A06 |
| VEL / PROB / RAT | velocity / вероятность / ratchet шага | `stepset` → step | нет | громкость / пропуски / дробь | A14, A15 |
| GENERATE | новый ритм/звук в scope | `generate` → `noizGenerate` | нет | новый паттерн (на след. такте при игре) | A06 |
| MUTATE | вариация от Keep | `mutate` → `noizMutateFromAnchor` | нет | узнаваемая вариация | A08, A09 |
| RHY / SND / PLK / ALL | область генерации | `scope` | нет | что меняется | A10, A12, A13 |
| KEEP | новая опорная точка | `keep` | нет | следующие Mutate от неё | A09 |
| UNDO | откат | `undo` (стек 16) | нет | возврат паттерна/anchor | A09 |
| AMOUNT | сила Mutate | `amount` → mutationAmount | один на всё устройство (D3) | 0% — без изменений | A07, A08 |
| LK DENS / LK AMT | вероятность и сила random P-Locks | `lockdensity` / `lockamount` | показываются только в PLK/ALL | точки P-Lock / тембровые вариации | A12, A13 |
| TONE | яркость | фильтр/частота партиалов (экспоненциально) | нет | темнее → ярче | A05 |
| DECAY | длина | время огибающей 8–1200 мс по голосам | нет | щелчок → длинный хвост | A05 |
| TEXTURE | окраска шума | white/pink/crackle; METAL: доля шума vs партиалы | нет | гладко → пыльно | A05 |
| DRIVE | насыщение | tanh(g·x)·g^−0.6 | нет | чисто → плотно без скачка громкости | A05 |
| CLR / BASE | очистить P-Locks шага / выйти из STEP | `clearsteplocks` / `selstep -1` | нет | точка P-Lock исчезает | A11 |

Нет ни одного контрола без связи с DSP или event engine. Ноды пока не аудиореактивны (P7) — их форма отражает только значение параметра.
