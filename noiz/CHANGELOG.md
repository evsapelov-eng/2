# Changelog

## 0.4.1 — 2026-11-10 (test build, not host-tested)

- GENERATE даёт каждому голосу новую длину цикла (обычно 5–16, иногда 20/24/32), всегда отличную от предыдущей; все четыре голоса не получают одинаковую длину — рисунок постоянно «расползается» (полиметрия). Деления 3:4/5:4/7:4/3:2 иногда добавляются сверху.
- 102 автотеста.

## 0.4.0 — 2026-11-10 (test build, not host-tested)

- GENERATE создаёт каждому голосу новый звук синтеза: случайный архетип из 5 (HISS: CLOSED HAT, OPEN HAT, SHAKER, TICK, AIR; DUST: GRAIN SHAKER, CRACKLE, SNARE NOISE, RIM, BRUSH; METAL: COWBELL, BELL, CLANK, TINE, GONG; ATMOS: SWELL, GHOST TOM, WIND, SUB THUMP, WASH), не повторяющий предыдущий, со случайными значениями всех параметров внутри его диапазонов; примерно каждый 5-й — WILD (почти полный диапазон).
- Все 9 базовых параметров каждого голоса гарантированно меняются при каждом GENERATE.
- Название звука видно на SEQ (под именем голоса) и на SYNTH.
- 101 автотест (в т.ч. «каждый голос звучит по-разному: яркость и длина различаются в разы» по модели звука).

## 0.3.2 — 2026-11-10 (test build, not host-tested)

- GENERATE: все 9 параметров каждого незащищённого голоса получают новый рисунок по шагам (раньше ~75%).
- MUTATE: гарантированно меняется каждое значение каждого незащищённого голоса — все базовые параметры звука и синтеза и значение каждого шага каждого параметра — по сравнению с тем, что звучало перед нажатием; величина зависит от AMOUNT, при большом AMOUNT часть рисунков перерисовывается целиком.
- Схема v4. 97 автотестов (в т.ч. «после каждого MUTATE изменилось каждое значение» при AMOUNT 5%, 25%, 100%).

## 0.3.1 — 2026-11-10 (test build, not host-tested)

- GENERATE рисует пошаговые «дорожки»: ~75% параметров каждого голоса получают значения на каждом шаге цикла; форма случайная (случайно / нарастание / чередование / волна / акценты / блуждание), глубина случайная; панорама часто раскачивается на всю базу.
- Дорожка не срезается у краёв диапазона: центр сдвигается так, чтобы форма помещалась целиком.
- Ручка голоса сдвигает всю дорожку параметра, сохраняя рисунок.
- MUTATE слегка двигает значения дорожек, при большом AMOUNT перерисовывает часть дорожек целиком.
- Схема v3: старые скрытые настройки случайных P-Locks заменяются новыми значениями.
- 94 автотеста.

## 0.3.0 — 2026-11-10 (test build, not host-tested)

- GENERATE / MUTATE меняют всё: ритм, звук, параметры синтеза, панораму и значения по шагам (кроме голосов с L).
- Все 9 звуковых параметров можно задать на каждом шаге; случайные P-Locks затрагивают все.
- Новый экран LANE: рисование значений любого параметра по шагам.
- SYNTH: картинка из модели звука (волна L/R по лог-шкале времени, 10 мс крупно, спектр, панорама+разброс); у каждой ноды свой знак; SYNTH в режиме STEP редактирует шаг.
- Модель голоса вынесена в общий ES5-модуль (UI и офлайн-проверки считают одно и то же).
- Исправлено до выхода в Live: `Math.tanh` отсутствует в legacy JS Max (превью упало бы); сборка теперь запрещает ES2015-функции.
- 88 автотестов (в т.ч. «каждая ручка меняет картинку»), 38 проверок модели звука.

## 0.2.0 — 2026-11-10 (test build, not host-tested)

- Упрощённый интерфейс: экраны SEQ / SYNTH, GENERATE/MUTATE по контексту экрана; удалены RHY/SND/PLK/ALL, LK DENS/AMT, DENS, R/S, BASE; одна кнопка L (защита голоса).
- Панорама: PAN как P-Lock-параметр, SPREAD (разброс по ударам, ratchet пролетает по стерео), генерация панорамы; панорама равной мощности в каждом экземпляре голоса.
- Модуль синтеза SYNTH: RESO, ATTACK, CHARACTER (HISS BODY, DUST GRAIN, METAL RATIO, ATMOS WIDTH), PAN, SPREAD, LEVEL + 4 макроса; превью огибающей; значения в Гц/мс/дБ/L-R.
- Схема данных v2 с миграцией v1.
- `tools/maxsim.js`: исполнение сгенерированных патчей голосов — каждый из 9 входов доказуемо влияет на звук.
- 82 автотеста, 38 проверок эталонной DSP-модели.

## 0.1.0 — 2026-11-10 (STATIC VALID, not host-tested)

- Ядро (ES5): модель состояния schema v1 (4 × 32 шага, P-Locks как Partial<sound>), нормализация, versioned сериализация с безопасным отказом.
- Планировщик по абсолютной позиции Live: Length, Division n:m, Probability (детерминированный hash), Ratchet с минимальным интервалом; lookahead 40 мс + `[pipe]`, учёт петли Live, flush на seek/stop.
- Generate (архетипы голосов, density, полиметрия не в каждом паттерне, ограничение 4-голосных стеков), Mutate от Keep anchor, Keep, Undo(16), locks Rhythm/Sound, random P-Locks (Lock Density / Lock Amount), применение на следующем такте при игре.
- DSP-граф 4 голосов (`spec/dsp_map.json`), poly~ на удар, мягкая защита мастера; эталонный офлайн-рендер с 22 проверками.
- Генератор и валидатор `.maxpat`; P1 hello-патч; диагностический jsui 760 × 169.
- 55 автотестов. Документация: решения, архитектура, план, приёмка A01–A26, инструкция для Live, API к проверке.
