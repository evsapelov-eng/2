NØIZ v0.2.0 — ТЕСТОВАЯ СБОРКА для Ableton Live 12 (Max for Live Instrument)
=========================================================================

СТАТУС: собрано скриптом, в Ableton Live НЕ проверялось. Это не релиз.
Файлы .amxd не «заморожены» (не Freeze), поэтому все файлы этой папки
должны лежать ВМЕСТЕ — устройство берёт из неё JS и голоса.

УСТАНОВКА
1. Распакуйте папку NOIZ куда угодно (например, ~/Music/Ableton/User Library/Presets/Instruments/NOIZ).
   Не переименовывайте и не разносите файлы внутри.
2. В Live перетащите из Finder (или из браузера Live → Places) файл
   «NØIZ P1 hello.amxd» на НОВУЮ MIDI-дорожку. Нажмите кнопку на устройстве —
   должен быть короткий «пшик». Это проверка, что Live вообще принимает
   такие файлы и звук идёт.
3. Перетащите «NØIZ.amxd» на новую MIDI-дорожку. Включите Play в Live —
   сразу играет встроенный паттерн (MIDI-ноты не нужны).

УПРАВЛЕНИЕ
Два экрана — переключатели SEQ / SYNTH слева вверху.
GENERATE / MUTATE действуют на то, что видно на экране:
  SEQ   → новый ритм + P-Locks (тембр и панорама отдельных ударов)
  SYNTH → новый звук: тембр, синтез, панорама и разброс голосов
AMOUNT — сила MUTATE. KEEP — запомнить вариант как основу. UNDO — назад.
Во время игры изменения применяются со следующего такта (NEXT BAR).

SEQ
- клик по квадрату — шаг вкл/выкл
- option+клик — выбрать шаг (STEP): ноды справа пишут P-Lock только этого
  шага; слева VEL / PROB / RAT шага; «x» — выйти; CLR — стереть P-Locks шага
- имя дорожки — выбрать голос; M — mute; L — защитить голос от GENERATE/MUTATE
- LEN / DIV — тянуть вверх/вниз (длина цикла, полиритм 3:4, 5:4 …)
- ноды TONE · DECAY · TEXTURE · DRIVE · PAN

SYNTH (выбранный голос, слева список голосов)
- TONE · DECAY · TEXTURE · DRIVE · RESO · ATTACK · BODY/GRAIN/RATIO/WIDTH ·
  PAN · SPREAD · LEVEL
  BODY (HISS): тонкий шорох → хэт с телом;  GRAIN (DUST): гладкий шум → пылинки
  RATIO (METAL): негармоничность обертонов;  WIDTH (ATMOS): ширина стерео
  SPREAD: каждый удар в своём месте панорамы, дробь (ratchet) пролетает по базе
Ноды: тянуть вверх/вниз по всей ноде, Shift — точно, двойной клик — по умолчанию.

ЕСЛИ ЧТО-ТО НЕ ТАК — пришлите:
- скриншот устройства;
- содержимое Max Console: на устройстве правый клик → Open Max Window
  (или кнопка Edit → Window → Max Console);
- что именно не работает.
Частые случаи:
- Live не открывает .amxd / показывает пустое устройство → соберите штатно
  по docs/HOST_TEST_GUIDE.md (те же патчи, но сохранённые самим Live).
- Интерфейс показывает «NOIZ UI error» → текст ошибки на устройстве и в Console.
- UI есть, но при Play нет «SYNC LIVE» и номера такта → часы (transport) —
  пришлите Console.
- Звук есть, но странный тембр/громкость — это настраивается, опишите на слух.

Файлы: NØIZ.amxd (инструмент), NØIZ P1 hello.amxd (проверка звука),
noiz_engine.js (движок), noiz_ui.js (интерфейс), noiz_voice_*.maxpat (голоса).
