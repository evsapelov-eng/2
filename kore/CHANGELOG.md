# Changelog

## 0.1.0 — 2026-11-10 (test build, not host-tested)

- Ядро на 6 голосов (PUNCH, SUB, RUMBLE, TOM L, TOM H, HAT), схема v1, параметры строго по голосам (без утечки P-Locks).
- Генератор техно-грува: 4 стиля, PUNCH 4/4 неприкосновенна, SUB/RUMBLE/томы/хэт по ролям, валидация с ограничением попыток; звук из архетипов; рисунки по шагам у всех параметров; длины остальных голосов меняются (D1–D5).
- MUTATE от KEEP: бочка почти не меняется при малом AMOUNT, остальные — каждое значение.
- DSP-патчи: PUNCH (sweep по τ, сброс фазы, клик, drive), SUB, TOM L/H, HAT (choke), шина RUMBLE (ограниченная обратная связь, гейт, duck), низ (SUB duck, DC, safety), индикаторы.
- UI: компакт 760×169 + редактор 1200×760 (SEQUENCE / SOUND с волной и графиком высоты из модели / LANES).
- 68 тестов (в т.ч. исполнение патчей и сверка с моделью), 5 офлайн-проверок низа и уровня.
