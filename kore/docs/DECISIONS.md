# KØRE — решения

## Решения пользователя (приоритет над ТЗ)

| ID | Решение | Отличие от ТЗ |
|---|---|---|
| D1 | GENERATE меняет ритм **и** настройки синтеза всех голосов (у каждого голоса новый архетип звука, все параметры случайно внутри него, каждое значение гарантированно меняется). | ТЗ §12: scope по умолчанию RHYTHM. |
| D2 | При GENERATE случайные значения получают **все шаги** (рисунок по шагам для каждого параметра каждого голоса). | ТЗ §12: P-Lock Chance 0.20 и только звучащие шаги. Заполняются все шаги цикла, чтобы включённый позже шаг уже имел значение. Глубины для PUNCH/SUB малы (тон ≤ ±0.5 полутона на ширину), см. `KORE_LANE_DEPTH`. |
| D3 | MUTATE при малом AMOUNT почти не трогает бочку; остальные голоса — каждое значение меняется. | Совпадает с §12 для бочки; для остальных — как в NØIZ. Звук/рисунки PUNCH сдвигаются на 0.3·AMOUNT² (при 15% < 1% диапазона). |
| D4 | У бочки меняется только синтез: ритм PUNCH всегда 4/4 на 0/4/8/12, длина 16, без ratchet. | Совпадает с §11.2. BROKEN может двигать якорь только при `unlockPunch` (Advanced, по умолчанию выкл). |
| D6 | v0.2: «бочки гуляют»; бочка должна быть пробивной техно-бочкой. | Бочка — один постоянный звук (без пошаговых значений и «призрачных» ударов), 4 удара силой 1, играется в сигнальной области от фазы транспорта (точность до сэмпла, не зависит от аудиобуфера Live). Звук рендерится моделью в buffer~ (двойная буферизация). MUTATE не трогает бочку никогда; GENERATE даёт новый техно-архетип (L сохраняет). |
| D7 | «Нет настроек каждого звука; редактировать визуально». | PUNCH 8 параметров (TUNE PUNCH TIME BODY DECAY DRIVE CLICK CLICK TONE), SUB 4, RUMBLE 5, томы 5, HAT 4. На SOUND точки графиков — параметры (кривая высоты, волна, спектр). |
| D5 | Длины дорожек остальных 5 голосов меняются при каждом GENERATE (как в NØIZ), из наборов стиля. | ТЗ разрешает полиметрию; здесь она в каждом паттерне. |

## Технические решения

| ID | Вопрос | Решение |
|---|---|---|
| T1 | Экспоненциальные огибающие и sweep высоты без gen~ | `[line~]` в дБ → `[dbtoa~]` (линейный дБ = экспонента). `2^x = dbtoa(6.0206·x)`. |
| T12 | Где играет бочка | `kore_kick.maxpat`: `phasor~ 1n @lock 1` → 16 шагов → `sah~` шага и силы на ударе → время с удара в сэмплах → `index~` по буферу. Из того же времени — сигнал близости удара для приглушения SUB/RUMBLE (тоже точно до сэмпла). |
| T2 | Смысл «SWEEP 30 ms» | Постоянная времени τ в `exp(-t/τ)` (ТЗ §03); в патче рампа −60 дБ за 6.9078·τ. Трактовка «до −60 дБ за 30 мс» давала τ≈4 мс — высота падала почти мгновенно. |
| T3 | Фаза старта | `cycle~` — косинус; сброс фазы в 0.75 = синус с нулевым стартом (детерминированный onset без ступеньки). |
| T4 | Ratchet/наложения без обрыва | PUNCH/SUB/TOMs — `poly~` (экземпляр на удар). HAT — 1 экземпляр + steal: новый удар перезапускает огибающую → закрытый глушит открытый. |
| T5 | RUMBLE | Шина эффекта от PUNCH: LP 220 Гц → 2 тапа 47/83 мс, feedback = min(0.85, 10^(−3·65/tail)); гейт по шагам RUMBLE; приглушение на каждом PUNCH. Не третья «бочка». |
| T6 | Low-End Coordinator | SUB приглушается на каждом PUNCH (−6 дБ, 2/140 мс; действует только если SUB звучит). Моно низ (все голоса моно). DC-блок 15 Гц, мягкий предохранитель, ceiling 0.94. Ручки не выводятся (ТЗ §08). |
| T7 | DRIVE и громкость | tanh(g·x)·g^−0.3, g = 1+8·drive: насыщение без роста пика (A06), стартовый пресет ≈ −8.5 dBFS. |
| T8 | Тайминг | Как в NØIZ: позиция Live, lookahead 40 мс + `[pipe]`, петля Live, flush на seek/stop, применение на следующем такте. |
| T9 | Компакт + редактор | jsui 760×169 в устройстве + `[p KORE_EDITOR]` 1200×760, открывается `[pcontrol] open`; оба читают одно состояние. |
| T10 | Стиль/BIAS | Один селектор STYLE (FOUNDATION/DRIVING/HYPNOTIC/BROKEN); BIAS не выводится (ТЗ §11: объединить, если избыточно). |
| T11 | Undo в Live Set | Не сохраняется (как в NØIZ); состояние, KEEP-якорь, seed — сохраняются. |
