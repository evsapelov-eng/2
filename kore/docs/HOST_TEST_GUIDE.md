# KØRE — проверка в Live 12

Пошагово для пользователя: `dist/KORE/README_FIRST.txt` (установка → проверка из папки → Freeze).

## Минимальный тестовый проект (ТЗ)

Пустой Set, MIDI-дорожка с KØRE.amxd, 130 BPM, 4/4, индикатор уровня виден. Save, выйти из Live, открыть снова, Generate/Mutate/Keep/Undo. Перенести **замороженный** KØRE.amxd в новый Set без исходной папки: отсутствие JS = FAIL (A36).
